# InsulinGlucoseControl
A public, extensible simulation and control suite for Artificial Pancreas control and estimation algorithm development. A comprehensive set of physiological models, controllers, estimators, analysis, data ingestion, system identification, RL, and related tools are intended to be added continuously, and hopefully expanded upon by the public research community.

# Cross-language interoperability
Part of the design intent is to maintain a subset of package-compilable features that will allow funcation calls from MATLAB/Octave, Python, C, and other Julia projects, with the InsulinGlucoseControl (IGC) package a as a dependency.
